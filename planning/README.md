# planning/

Idea evolution and work in progress. This is where thinking happens.

## What goes here

- Specs being drafted
- MoSCoW lists
- Architecture sketches and diagrams
- Research notes
- Build protocols
- Anything incomplete, evolving, or superseded

## What doesn't go here

- Final documents ready for delivery → `docs/`
- Design docs for specific code modules → co-located with the code
  (e.g., `core/bundles/DESIGN.md`)

## Convention

Files here are working documents. They may be messy. They may contradict
each other. That's fine — they're thinking, not deliverables. When a
document is finished and ready for someone else to read, promote it to
`docs/`.
